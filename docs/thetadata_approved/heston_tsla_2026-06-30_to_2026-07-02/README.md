# Approved Theta Data Heston/SSVI aggregate evidence

This isolated directory contains the complete and exclusive set of approved aggregate artifacts
for the TSLA options Heston/SSVI case study covering 30 June through 2 July 2026. It contains no
raw or processed quote rows, individual contracts, actual strikes, NBBO observations, bid/ask
values or sizes, API responses, caches, per-strike IV or fitted values, ranked candidates, or
detailed trade cases.

This project is independent research by the author and is not reviewed, endorsed or sponsored by Theta Data.
